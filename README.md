## À propos

Je conçois des produits numériques complets, du design à la mise en production, avec une spécialité : **l'automatisation et l'IA appliquées aux métiers réels** (restauration, hôtellerie, droit, commerce, tourisme).

- Workflows d'automatisation **n8n** connectés à WhatsApp, CRM, paiements et bases de données
- Agents IA et **LLM RAG** : assistants métier, concierges, chatbots juridiques
- Applications web **Next.js / React** avec back-end **Supabase**, déployées sur Vercel
- Identité visuelle et UI : chartes graphiques, design systems, interfaces soignées
